개인정보처리방침

시행일: 2026년 10월 8일

이 정책은 개인용 프로젝트 GCP-JupyterLab-Borderless의 rclone 기반 Google Drive 연동에 적용됩니다. 본 웹사이트는 안내용 정적 페이지입니다.

1. Google Drive 데이터에 접근하는 목적

운영자가 직접 승인한 Google 계정의 Drive 안에서 지정된 데이터 수집 결과 폴더를 확인하고, Python 수집 작업으로 생성한 JSON/TXT/JSONL 파일을 업로드·갱신하며, 필요 시 이전 오류 표시 파일을 정리합니다.

2. 접근하는 정보

Google OAuth를 통해 운영자가 허가한 Google Drive의 파일 및 폴더 메타데이터와 콘텐츠에 접근할 수 있습니다. 현재 개인용 작업에서 지정된 폴더의 파일 동기화에 이용합니다. 인증에 필요한 OAuth 토큰은 운영자 서버의 rclone 설정에 저장됩니다.

3. 저장·이용·보유

수집 결과 파일은 운영자 지정 Google Drive 폴더와 운영자 관리 서버에 저장됩니다. 운영자가 삭제하거나 접근 권한을 철회할 때까지 파일과 인증 설정이 유지될 수 있습니다. 본 GitHub Pages 웹사이트에는 Google Drive 파일이나 OAuth 토큰을 게시하지 않습니다.

4. 정보 공유

운영자의 Google Drive 데이터는 광고 목적으로 이용하거나 판매하지 않습니다. 데이터 전송과 저장에는 Google Drive API 및 rclone이 사용됩니다. 운영자가 별도로 Drive 파일의 접근 권한을 부여한 경우에는 해당 권한 범위에서 다른 사람이 볼 수 있습니다.

5. 보안 및 권한 철회

운영자는 서버의 rclone 인증 파일과 API 인증 정보를 비공개로 관리합니다. Google 계정의 제3자 연결 관리에서 앱 권한을 철회할 수 있으며, 서버에 저장된 rclone 토큰과 Drive 파일도 직접 삭제할 수 있습니다.

6. 정책 변경 및 문의

작동 방식이 변경되면 이 문서를 갱신합니다. 문의는 운영자 GitHub 프로필을 이용해 주세요.
